# Reports

**Convention set by Ryan, 2026-09-04.** Working reports from build sessions are
written here, committed and pushed **as part of the same chain as the work they
describe**, and referred to in chat by path only.

    docs/reports/YYYY-MM-DD-NN-slug.md

`NN` is a per-day sequence. The master session reads them from
`raw.githubusercontent.com`, which works reliably where file attachments between
sessions do not.

**Two rules carried over from the commit discipline:**

1. **Push before reporting.** A report the reader cannot reach is worse than no
   report.
2. **If a push is blocked, say so in chat** with the branch and commit hash.
   Do not route around it.

Chat summaries stay to a few sentences plus the path. The detail lives here.

These are *reports* — what was measured, when, by what method, and what it means.
Durable rulings go to `DATASET_DESIGN.md`; durable method findings go to
`DATASET_PRECEDENTS.md`. A report is the working record behind both.
